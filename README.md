# RandomProblem
random atcoder problem
# My Discord Bot

## 機能
- /を打った後  all,abc,arc,agcと打つことでそれぞれ全コンテスト,ABC,ARC,AGCのそれぞれの全問題から一問出題される.
- /abc,arc,agcと打った後で_a,_bなどを打つと,それぞれのコンテストの選んだ問題がランダムに一問出題される.

## セットアップ
1. `.env` に `DISCORD_TOKEN=トークン` を記入
2. `pip install -r requirements.txt`
3. `python rp.py` で起動
